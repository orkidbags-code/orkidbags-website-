# Pritam & Co. — ORKID Bags

The static public website for Pritam & Co., a bag manufacturer/exporter based in Tronica City, Ghaziabad, India.

**Website:** https://orkidbags-code.github.io/orkidbags-website-

**GitHub Pages source:** `main` branch, repository root

The catalogue contains **20 distinct product photographs**: the 17 images supplied by the company plus three additional images linked to Pritam & Co.'s public TradeIndia product listings. Those added cards show only listing-backed specifications; prices, minimum order quantities and availability are not copied because marketplace information may change. Photo references are not official SKUs.

This is a **production-built static website**. Its root `index.html`, hashed JavaScript/CSS and local fonts, logo and bag photographs can be served by GitHub Pages without Node.js, a web server, a database or backend credentials. `orkid-github-pages-dist.zip` contains only the deployable build files, with `index.html` at the ZIP root.
